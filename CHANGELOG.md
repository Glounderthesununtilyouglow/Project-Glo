# Changelog

All notable changes to Project Glo will be documented here.

## [0.3] - 2026-11-15

### Added
- 10:00 AM New York opening-price detection
- Exact opening-price visualization
- Independent 1-minute, 3-minute, and 5-minute retest detection
- Bullish and bearish confirmation markers
- Preliminary structural stop-loss and take-profit calculations
- Minimum 1:3.5 risk-to-reward filter
- One-trade-per-day restriction

### Known Limitations
- Retest detection requires further validation
- Structural liquidity targeting is provisional
- Multi-timeframe signal synchronization requires testing
- Historical profitability has not been established
- Live trading integration is not implemented
